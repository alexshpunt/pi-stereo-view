# Stereo View for Herdr

This experimental mod shows Pi's Conversation and Activity histories in independently scrolling native panels. Pi owns the editor, dialogs and widgets. Editor-slot dialogs appear with history, and overlays are projected over it. Pi's picker placement preference controls whether its windows appear with combined history, full-width Activity or the split panels. Widgets from above and below Pi's editor share a strip below history, above the composer. Keyboard input and pointer movement, wheel, and left, middle and right button gestures go to their live Pi components. When a component does not handle the wheel, the projected surface scrolls instead. The panels follow new output until you scroll away; scrolling back to the end resumes following. The toolbar controls layout and panel settings. Find searches the corresponding panel. The terminal remains available as a fallback.

The mod renders terminal image placements as native images. It fetches their data from the originating Pi in bounded chunks, verifies it locally and keeps decoded images in `data/stereo-view/images` under the Herdr app home. Each mod runtime uses a separate image directory; subsequent runs remove directories owned by processes that have exited. Files from the older shared cache are left in place because another app may still use them. Node.js must be on the app host's PATH and on the Pi terminal machine's PATH. When an image cannot be loaded, its panel shows a placeholder; the terminal remains available.

Install the `stereo-view` mod folder under the Herdr app's `mods` folder. In a Herdr App with pane views, switch the Pi terminal pane to GUI to show Stereo View in place. In older Herdr versions, open the Stereo View app for the running Pi terminal or put it beside the terminal with `app.beside`. Automatic app-tab opening is disabled: the running App does not expose a read-only capability signal to distinguish pane-view support from older versions. Manual app opening remains available.

The mod expects `origin` (or `terminal`) to identify the Pi terminal. Its bridge label carries version 1, the Pi PID and a socket path matching `/tmp/stereo-XXXXXX/s`, where each X is an ASCII letter or digit. The PID must still be the terminal's root or foreground process. The socket protocol uses one UTF-8 JSON request and response, each terminated by a newline. The fixed Node client runs on the terminal's machine; it does not execute a label-provided command or script. Requests are limited to 4 KiB, responses to 4 MiB and connections to three seconds. The mod retains bounded row pages and fetches around each viewport. The terminal remains available if the bridge is missing or fails.
